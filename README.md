# WBFFMH Appointment App

Monorepo generated by `generate_appointment_app.py`.

- `backend/`: Express 5 + PostgreSQL/Neon API.
- `frontend/`: React 19 + Vite frontend for Vercel.
- `backend/scripts/sql/`: all application SQL query constants.
- `scripts/`: local development/build/reset helpers.

## Default administrator
The first backend startup creates the requested administrator account:
`wbffmh@gmail.com` with the supplied initial password. Change it immediately in a production environment.

## Production configuration
Copy the generated secrets from `backend/.env` into Render Environment Variables rather than committing them to source control. Configure `VITE_BACKEND_URL` in Vercel to the Render API URL ending in `/api`.

Google Drive recording upload requires Google OAuth refresh-token credentials. Browser recording uses MediaRecorder and requires the browser's screen/capture permission; the Jitsi iframe itself is isolated by browser origin security.
